1. What has been done

We've been translating the first part of testsimul.pro (Andrei's IDL) into Python inside testsimul.ipynb. That first part is the piece that generates the simulated ring-image data cubes; the later reduction steps (statmom.pro, getweight5.pro, profrest5.pro) are the standard processing tools also used in normal operations, so we don't need to re-do those fully, Andrei and/or Adam already have them in
Python.

Concretely, the following IDL stages are now translated and running end-to-end in testsimul.ipynb:

  - readpar('sim1.par'): instrument/site parameters (d, effl, eps, pixel, wavelen,
    pdist, ringradpix, mmax, nsect, ron, weightfile, etc.) plus the observing
    parameters (seeing, zlow, zhigh, highfrac, starmag, gain) are defined directly
    in notebook cells. r0 and the turbulence integral J (tint) are computed from
    seeing exactly as in the .pro. A proper file-based reader for sim1.par is still
    a stub (cell "#par = with open data sim1.par ...").

  - simatm (simatm.py): DONE. Simulates the complex-amplitude screen for a two-layer
    atmosphere (low + high), builds Fresnel filters, generates Kolmogorov phase
    screens via FFT, propagates high layer -> low layer -> ground with the angular
    spectrum method, and saves everything to atm.npz (u1, ngrid, pixel, wavelen,
    see, r0, highfrac, zhigh, zlow). Also computes the Rytov/scintillation
    diagnostic and writes atmsim.jpg. Exists both as a standalone script (simatm.py)
    and as a notebook cell. Supports an optional fixed RNG seed (seed0) for
    reproducibility.

  - ringsim (ringsim.pro): DONE as a notebook cell. Loads atm.npz, applies wind
    blur (screen averaging over nblur sub-steps), builds the aperture mask with
    central obstruction, adds defocus (a4) and matching spherical (a11) Zernike
    terms, forms the Fresnel/pupil -> focal-plane ring image, oversamples/rebins to
    CCD pixels, slides the aperture across the screen frame-by-frame (with x/y
    slide and roll-over), and adds photon (Poisson) + readout noise per frame. It
    builds the 3D cube and also writes a live-preview ringsim.gif and the average
    image imav. NOTE: the standalone ringsim.py is currently only an argparse
    skeleton (arg parsing copied from simatm.py) — the actual simulation body has
    NOT yet been moved out of the notebook into that script.

  - writefits (writefits.pro): DONE as a notebook cell. Writes the cube to a FITS
    file with a header carrying the keys cube2.py expects (DATE-OBS, TELESCOP,
    WAVELEN, PIXSCALE, EXPOSURE [microseconds], MAG, SEEING, CONJ_H, INST, GAIN,
    STAR). Filename is prompted interactively. Output files present in the folder
    include test.fits, sim_ring_cube.fits, and 1000exps.fits.

  - cubecoef (cubecoef.pro): DONE as a notebook cell, and also runnable via Adam's
    adam/cube2.py (invoked with %run ./adam/cube2.py test.fits ./ ./). The notebook
    version reads the cube, builds the per-sector radial/flux masks and the
    piston-subtracted cos/sin angular masks (up to mmax), centers each frame with a
    Fourier phase-shift, projects every frame onto the mask matrix to produce the
    coefficient array coef, and assembles the impar dict (backgr, flux, fluxvar,
    rad, rwidth, xc, yc, xcvar, ycvar, coma, angle, contrast, noisepar). It also
    writes a centroid-tracking preview cube_centroid.gif.

  - statmom (statmom.pro): DONE as a notebook cell (the cell was fixed in commit
    b353543). Computes DIMM-like differential-radius variance and its noise, the
    angular power spectrum (power) and 1-lag covariance (cov), and the mean
    aberration coefficients (mcoef). Packs results into the moments dict and a
    combined data dict {image:{impar, noisepar}, moments}.

  - getweight5 / profrest5: already available in Python in adam/ and andrei/
    (getweight5.py, profrest5.py). Inputted into the notebook. These are the heavy-workers
    of the simulation, as they recreate what the program will be doing at night.

    getweight5 (computeweight -> aweight): builds the FORWARD model that links
    turbulence to the observables. On a log-spaced altitude grid (z, ~0.25-32 km)
    and for every angular frequency m (0..mmax), aweight propagates the ring-image
    response through Fresnel diffraction to produce the weighting matrix wt0 (how
    much a unit turbulence integral J at each layer contributes to the variance of
    each angular coefficient) and the U-functions ufunc (used for the wind
    response). It first back-solves the conjugation distance pdist from the ring
    radius, then computes weights for two star colors (B-V=0 and B-V=1) to capture
    the chromatic slope, derives the wind coefficients ucoef for a selected set of
    frequencies, and serializes everything (z, wt0, wtslope, ucoef0, ucoefslope,
    umm, lameff, ringrad, pdist) to weights.json. It is run once per instrument
    configuration, not per cube.

    profrest5 (restore): the INVERSE step, run on every cube at night. It takes the
    measured moments (angular power var, 1-lag covariance cov, radius variance
    rvar), the ring parameters (impar), the noise parameters, and the star geometry
    (zenith distance, B-V color), interpolates the weights onto the profile height
    grid z0 and stretches them by 1/cos(zen). After subtracting photon/readout
    noise and applying finite-exposure and saturation (Z-matrix) corrections, it
    solves a weighted non-negative least-squares (NNLS) system to recover the
    turbulence profile (the Cn^2 integrals per layer). From that profile it derives
    total and free-atmosphere seeing, an independent sector/radius-variance seeing,
    the wind speed (via the U-functions), the coherence time tau_0, and the
    isoplanatic angle theta_0. Together the two stages close the loop: getweight5
    maps turbulence -> observables, profrest5 maps observables -> turbulence profile
    plus integrated parameters.

New helper utility written alongside the translation:

  - zernikeplots.py: DONE. Standalone CLI that reads plain-text Zernike-coefficient
    files from a folder ("<index> <value>" per line), aggregates a chosen set of
    Zernikes across all files, and saves one histogram JPG per Zernike with mean,
    median and sigma annotated. Useful for inspecting the distribution of simulated
    aberrations. Invoke with --folder (required), plus optional --zernikes,
    --pattern, --bins, --prefix.

2. Ongoing work

but it still needs troubleshooting and bug fixing, besides the adaptation to stand alone
